# 2D Array - DS - additional badge practice

Problem: https://www.hackerrank.com/challenges/2d-array/problem

## Approach
Evaluate all sixteen seven-cell hourglasses and retain the maximum sum.

## Complexity
Time: O(1) for the fixed 6x6 grid. Space: O(1) auxiliary.

## Notes and tests
Initialize to -63, the minimum possible seven-cell sum with values at least -9, so negative grids work.

3 function checks and 1 stdin/stdout cases are included. Run `python run_tests.py`.
