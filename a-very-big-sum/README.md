# A Very Big Sum - additional badge practice

Problem: https://www.hackerrank.com/challenges/a-very-big-sum/problem

## Approach
Accumulate with long long so a sum larger than 32-bit int is preserved.

## Complexity
Time: O(n). Space: O(1) auxiliary.

## Notes and tests
